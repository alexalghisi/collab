# Assets

This directory holds the app's visual assets:

- `icon.png` — application icon used by Expo (iOS, Android adaptive icon, web favicon) and the desktop packagers.
- `demo.gif` — recording of a local run referenced at the top of the root `README.md`: the dashboard, a new meeting with its invite link, a second participant joining from that link, both cameras live, in-call chat, and the shared editor. Recorded against `npm run server:start` and a static web export, with Chrome's test capture device standing in for a webcam.
